Introduction The fast expansion of the Internet and social media platforms in recent years has resulted in an overwhelming quantity of information being shared and consumed by people worldwide. While this has clearly aided the dissemination of information and worldwide communication, it has also given rise to a troubling issue known as false news or fake news (Minocha et al., 2022). Fake news is content that is purposefully produced or deceptive and published as actual news, generally intending to deceive or manipulate readers (Helmstetter & Paulheim, 2021). The spread of false news has become an essential issue since it may have far-reaching effects on people, societies, and even public perception (Narayan, 2021). To build efficient fake news detection systems, academics and practitioners have investigated different machine learning and deep learning approaches (Kumar & Kar, 2023; Kirn et al., 2022). These systems employ artificial intelligence to automatically identify and categorize fake news, helping users in discriminating between true and false information (Ganegedara, 2022). However, the dataset is the main source for the credibility and trustability of machine learning and deep learning approaches (Helmstetter & Paulheim, 2018; Shu et al., 2020). The existing literature suffers from the limitation in the number of quality and reliable fake news datasets. Thanks to Dadkhah et al. (2023), A large-scale ground-truth fake news dataset called TruthSeeker is now publically available. This dataset has been collected from Twitter between 2009 and 2022 with more than 130,000 samples. The dataset has been labeled using Amazon Mechanical Turk. The main distinguished point regarding the ground-truth TruthSeeker dataset is that it is validated using a rigorous procedure to ensure its quality and reliability. In the original paper on the TruthSeeker dataset, the authors described the dataset design and generation and explored the correlation between tweet labels and online creators’/spreaders’ characteristics. They also fine-tuned the BERT transformer to build a fake news detection system. They found that the experimental results showed significant improvement for models dealing with short-length text in solving a false information dissemination problem.
However, the quality of this dataset is still questionable and required additional investigation to ensure its trustability for building fake news detection system. This research continues that research line and investigates the impact of different text representations in addition to the hand-crafted features on the performance of deep learning. The Truthseeker also contains hand-crafted features that describe the lexical and text properties. These features were generated from the original tweets. Therefore, in this paper, we investigated the benefits of three types of text representations: word2vec, TFIDF, and Deep contextualized text representation using transformers. We build multiple experiments to examine the performance of deep learning and machine learning based on three main scenarios: (1) using only the handcrafted features, (2) using text embedding features that will be generated from text representation techniques, and (3) using both handcrafted features and text embedding features.
The conducted research is driven by the following research questions:
- RQ1: which features are sufficient to build an accurate fake news detection system based on Truth seeker dataset?
This question is designed to explore the impact of text embedding features and hand-crafted features on the performance of fake news detection system. Since the dataset contains two categories of features: handcrafted features that describe statistical properties from the original text and text feature that describes the original content of the tweets. The text feature will be converted into an embedding features using text representation techniques. In this part, multiple text representation techniques have been used such as word2vec, Term Frequency-Inverse Document Frequency (TF-IDF) and advanced Large Language Models (BERT and RoBERTa). To address this question, we build multiple classification models based on hand-crafted features, and we build classification models based on text embedding features. Furthermore, we also investigated the combination of handcrafted and text embedding features. Then, we compared the results.

- RQ2: Which kind of text representation is more suitable for this dataset?
This question is designed to examine which kind of text representation techniques is most suitable for fake detection models in case we use text feature only or when we use handcrafted features and text features together. To address this question, we used three main text representation techniques: TF-IDF, word2vec and deep contextualized text representation based transformers (BERT and RoBERTa).

Background This section describes the employed machine learning algorithms and text representation techniques.
Machine learning algorithms Multiple machine learning algorithms have been used to develop fake new detection systems. The choice of these algorithms was based on their popularity and accuracy in classifying data. The complete list of the employed machine learning algorithms is as follows:
- Decision Tree (DT): It is a classifier that uses a tree structure, where internal nodes represent the features, branches represent the decision-making process, and each leaf node represents the classification result. The Decision Node and Leaf Node are the nodes of a decision tree. The Leaf nodes are the results and do not have any more branches; decision nodes are used to create decisions and have numerous branches. It is usually used for classification problems.

- Logistic Regression (LR): It represents a logistic function by a sigmoid equation that predicts two values (0 or 1) When a variety of data sources are used, logistic regression classifies observations and quickly determines the components that will function effectively.

- K-Nearest Neighbors (KNN): This method uses the similarity concept to classify the new data points after sorting all the existing data, which can be quickly and accurately sorted into a suitable category. This method is called a lazy learner algorithm because it saves the training dataset instead of learning from it immediately.

- AdaBoost (AB): stands for Adaptive Boosting; this method uses the “boosting” concept, which is an ensemble learning technique that transfers a group of weak learners into strong learners to reduce training errors. At each iteration, the weights of the weak learners are increased so that the next model will focus on the weaknesses of the previous models and improve its performance. These learners are other classification methods like DT, KNN, LR,..etc

- Random Forest (RF): It is an ensemble learning method that integrates different classifiers to address complex issues and enhance model performance. It contains a group of decision trees on various subsets of the given dataset and calculates the average to improve the accuracy of that dataset rather than one decision tree; the random forest uses forecasts from each tree and predicts the result based on the votes of the majority of predictions. The cause behind the several decision trees is to achieve Higher accuracy and to avoid overfitting.

- Gaussian Naive Bayes (GNB): It is a supervised learning method for classification problems that depends on the Bayes theorem. It is employed in text categorization with an extensive training set. The Naive Bayes Classifier is a straightforward and efficient classification algorithms.

- Support Vector Machine (SVC): It works by finding the optimal line, which is the decision separator that can separate n-dimensional space into classes so that we can classify any new data points in the future. The created plane is called the hyperplane, which is the best decision boundary. SVM creates this hyperplane by selecting the extreme points and vectors, which are used to represent these extreme instances.



Text representation Text representation in Natural Language Processing (NLP) refers to the process of converting textual data into a format that can be effectively processed and analyzed by machine learning models. Text data, such as sentences or documents, is inherently unstructured and cannot be directly used for most NLP tasks. Therefore, text representation techniques are employed to transform this unstructured text into a structured numerical format that can be input to machine learning algorithms. Text representation serves several key purposes in NLP, such as Feature Extraction, Semantic Understanding, Dimensionality Reduction, and Machine Learning Compatibility. Patil et al. (2023), Mayil and Jeyalakshmi (2023), Srivasatava et al. (2017), Guo et al. (2021) and Özdil et al. (2021). The common methods for text representation in NLP are:
- One-Hot Encoding: In one-hot encoding, each word or token in the text is represented as a binary vector where only one element is set to 1, and all others are set to 0. This simple method lacks semantic information and can result in high dimensionality.

- Bag of Words (BoW): BoW representation counts the frequency of each word in a document or corpus and represents a text as a vector of word counts. It is simple to implement but does not capture word order or semantic relationships.

- Term Frequency-Inverse Document Frequency (TF-IDF): TF-IDF is a more advanced representation that considers both the frequency of a word in a document and its importance in the entire corpus. It helps identify discriminative words for a particular document but not common across the entire corpus.

- Word Embeddings: Word embeddings, such as Word2Vec, GloVe, and FastText, are pre-trained neural network models representing words as dense, continuous-valued vectors. These vectors capture semantic relationships between words and can be fine-tuned for specific NLP tasks.

- Sentence and Document Embeddings: Besides word embeddings, there are techniques to generate vector representations for entire sentences or documents. Methods like Doc2Vec and Universal Sentence Encoder can represent the meaning and context of entire texts.

- Transformer-based models, like BERT, RoBERTa, and GPT, have become popular for text representation. They capture contextual information by considering the entire sentence or document and have achieved state-of-the-art results in various NLP tasks. Transformer models are a class of deep learning models introduced in a 2017 paper titled “Attention Is All You Need” by Gillioz et al. (2020). Transformers have also found applications in computer vision and other domains due to their ability to capture and model complex relationships in data. Encoder and Decoder are the components that make up the Transformer, essentially an end-to-end Seq2Seq structure. The Encoder is in charge of comprehending the original text, while the Decoder produces translations (Vaswani et al. 2017).



Literature review Many researchers have been focusing on the area of social media to find the reality of the hugely generated posts every day.This section provides an overview of different methods used by the researchers to create fake detection systems applied to social media data and Table 1 introduce the summary of this literature review.
di Tollo et al. (2023) extracted sentiment from Twitter using stochastic neural networks, which are natural language processing (NLP) with the neural networks (NN), They predicted the trend direction by finding the best parameters setting of external evolutionary algorithm. They achieved stable and reliable accuracy across various previous systems.
Vaiyapuri et al. (2023) Created a novel Marine Predator Optimization with Natural Language Processing (MPONLP-TSA). Their model focused on identifying the sentiments that were prevalent in the Twitter data during the COVID-19 epidemic. They used Word vectors using the BERT model. They used a bidirectional recurrent neural network (BiRNN) model to find and categorize sentiments.
Xie et al. (2023) created a content classification and sentiment analysis model utilizing COVID-Twitter-BERT on a smaller COVID-19 tweet sample. The range of the classification accuracy for the five identified themes was 0.77 to 0.88. BERT attained an accuracy of 0.7 in the sentiment analysis using three classes of classification (positive/negative/neutral). Then, they used a larger dataset of more than 4 million tweets over a 15-month period, they applied the content topic and sentiment classifiers.
Sufi (2023) introduced a new multidimensional framework for cyber intelligence and utilizes Twitter data to generate reports for Russia and Ukraine conflict. The generation process is automated, employing advanced monitoring tools and NLP algorithms, including language translation, detection, sentiment analysis, latent Dirichlet allocation, term frequency-inverse document frequency, Porter stemming, and n-grams. The perplexity is used to evaluate this model.
Gamal et al. (2019) used Sentiment classification and different machine learning algorithms to predict if the textual content implies is a positive or negative review.For all of the employed datasets (IMDB, Cornell Movies, Amazon, and Twitter), the Passive Aggressive (PA) with a unigram outperformed all other algorithms, and it yields values that vary from 87 to 99.9 percent for all evaluation metrics.
Ryciak et al. (2022) tried to find anomalies in the log files of the system using the NLP field. They discussed a literation of the LogEvent2Vec algorithm, and they applied different classifiers, which are AdaBoost(AB), Gaussian naive Bayes(GNB), Random Forest(RF), Decision Tree(DT), gradient boosting(XB), and multilayer perceptions(MLP). They explained that using a short log sequence and the best classifier (in this case, MLP) they achieved excellent results, with a 0.997 F1 score compared to the baseline system’s 0.886.
Hisham et al. (2023) Investigated methods for detecting fake news sources, authors, and subjects on online social networks. They used an open-source online dataset of fake and real news to determine the credibility of news. Various text feature extraction techniques and classification algorithms are reviewed, including Support Vector Machine (SVM) linear classification algorithm using TF-IDF feature extraction, Random Forest (RF), and Naive Bayes (NB). The SVM algorithm performed the highest accuracy of 99.36% in detecting fake news, followed by RF with 98.25% accuracy and NB with 94.74% accuracy.
Madani et al. (2023) proposed a two-phase strategy to identify fake news using machine learning and natural language processing to detect fake news and they introduced two new structural features, along with other key features, extracted from news samples in the first phase of the model.They implemented a hybrid method based on curriculum strategy, statistical data, and a k-nearest neighbor algorithm in the second phase to improve the performance of deep learning models. Khanam et al. (2021) examined various textual properties that can be utilized to differentiate fake and real news. To increase the accuracy of the machine learning models, they preprocessed the data using techniques for natural language processing. They trained various machine learning classifiers with all possible combinations of the extracted and preprocessed properties and evaluated the built models using various performance metrics. Naive Bayes algorithm achieved the best performance in their model.
Some researchers used graphic methods to detect fake news, such as Nguyen et al. (2020), who presented the Factual News Graph (FANG), a cutting-edge learning framework and graphical social context representation for identifying false news. They concentrated on representation learning instead of performance, as was the focus of earlier contextual models. In contrast to transductive models, FANG is efficient at inference time, requiring no reprocessing of the complete graph, and scalable during training since it does not require the maintenance of social entities engaged in transmitting other news.
Also, Tam et al. (2019) demonstrated how to use a graph-based scan technique to identify rumors at the network level based on local anomalies. They developed a rumor detection system that spots irregularities in a social platform’s user base, post content, and hashtag usage, as well as in the relationships between these entities. Furthermore, they suggest step-by-step techniques that allow them to use social platform streaming data to identify rumors.
Park and Chai (2023) used XGBoost model to determine the significance of each variable in detecting fake news, identifying priority factors. Then employed SVM, RF, LR, CART, and NNET-representative machine learning classification models-using the derived variables to compare their performance in fake news detection.
Existing research in fake news detection highlights two key limitations:
- Dataset Quality: The effectiveness of fake news detection models is heavily influenced by the quality of the datasets used for training and evaluation. Datasets with inherent biases or inconsistencies can hinder model performance.

- Model-Representation Instability: Studies have observed an absence of a single, universally effective text representation technique for fake news classification. The dynamic and often deceptive nature of fake news content necessitates a multifaceted approach.


This paper proposes a approach to address these challenges in fake news classification. We leverage a high-quality, well-established ground truth dataset, TruthSeeker, to train and evaluate our models. Additionally, we explore the efficacy of combining various text representation techniques with hand-crafted features. By incorporating a diverse range of features - both learned and handcrafted - we aim to capture a more comprehensive representation of the underlying characteristics of fake news. Text representation techniques, such as word embeddings and TF-IDF, offer valuable insights into the semantic relationships and word usage patterns within news content. Hand-crafted features, carefully designed based on domain knowledge, can capture specific elements indicative of deception or manipulation strategies. The combination of these feature sets empowers the model to learn from a richer information landscape, potentially leading to more robust and generalizable fake news detection capabilities. Table 1. Research methodology The experiments were conducted on the Google Colab platform using Intel(R) machine (13 th Gen, 3GHz speed, Core(TM) i9-13900KF with one NVIDIA GeForce RTX 4080 GPU, 32 Gigabytes of RAM). The models were developed using NumPy, Panda, Scikit-learn, Python Torch, Keras, and Tensorflow libraries.
Dataset Finding reliable and high-quality fake news datasets that are correctly labeled is not straightforward. Dadkhah et al. (2023) collected and truly labeled a social media fake news dataset. The dataset 134,198 labeled samples, and it has been validated through a rigorous labeling system using Amazon Mechanic Turk. The tweets are labeled as Real and Fake news based on ground truth values, where 68,985 samples are labeled as True, and 65,213 are labeled as False.
Unlike other datasets in the literature, this dataset contains two categories of features: handcrafted features and text features. The handcrafted features describe meta-data properties of tweet accounts in addition to text and lexical statistical features. The remaining feature category is the original text content of the tweet. The complete description of these features can be found in this link1
Dataset preprocessing The dataset is almost clean, but some important actions are required to ensure the quality of the final version of the dataset. First, we checked numerical features against missing values and outliers, but we did not find any problem with the data. Some columns have the same information, like the BotScore column and BotScoreBinary, so we deleted the ’BotScore’ column. The statement column contains the title of the main subject of each tweet; there are 1058 statements, so we transferred them to categorical labeling. Majority_target is the target variable of the dataset, which contains True or False labels. This variable has been transformed to True: 1 and False: 0. Finally, the columns with zero values (around 24 features) have all or more than 70% of their values zero, so we exclude them from the final version of the dataset.
To build the text representation models, we followed a typical text pre-processing pipeline for tweets as follows:
- Text Cleaning: we removed the special characters by eliminating punctuation, symbols, and other non-alphanumeric characters that don’t carry significant meaning. Then, we removed URLs by deleting hyperlinks, as they typically do not contain meaningful information for embedding. And we handled numerical Values, emoticons, emojis, mentions, and hashtags by removing them from the tweet.

- Tokenization: we split the tweet text into individual words or tokens. Tokenization is essential for breaking down the text into units that can be processed and embedded individually.

- Case Folding: we converted all texts to lowercase. This standardizes the text and ensures that words with different letter cases (e.g., “apple” and “Apple”) are treated as the same word.

- Stop Word Removal: we removed common stop words (e.g., “the,” “and,” “in”) that do not carry much information and may introduce noise.

Evaluation results As we mentioned earlier, the Truth dataset contains two categories of features, which are handcrafted features and text features. To get insight into the performance of these categories individually and together for detecting fake news on social media, we constructed three main experiments. The first experiment examines the performance of handcrafted features and the top 10 handcrafted features for fake news detection. The top 10 handcrafted features have been selected based on way ANOVA test. The second experiment focus on converting text to embedding features using different text representation techniques such as word2vec, TF-IDF, BERT, and ROBERTA. The third experiment focuses on combining both text embedding features and handcrafted features together.
Before we get deeply into the results, we should acknowledge that using recent advanced text representation techniques based on Large Language Models (LLMs) can generate better word and sentence embedding vectors. However, other factors could play an important role in the meaningful of the generated embedding vectors, such as the size of the corpus, masking techniques, size of the original LLMs in terms of encoders, and the domain that we targeted. Therefore, that does not mean that these advanced text representation techniques will always outperform other text representation techniques because methods like word2vec and TF-IDF could also help produce meaningful text representations. In this part, we investigate this issue thoroughly based on multiple experiments. The results of the first experiment are summarized and presented in Table 2. The Table is structured into two main parts: all handcrafted features and the top 10 handcrafted features. The top 10 handcrafted features have been selected by applying one one-way ANOVA F-test statistics method to determine the most important features contributing to the fake news classification model. The main hypothesis of the algorithm is to test whether or not all the different classes of the target feature have the same mean as an input handcrafted feature. The obtained value of the F-test can be interpreted as follows: the higher the F-value in an ANOVA, the higher the variation between sample means relative to the variation within the samples. It is important to note that the higher the F-value is usually associated with the lower the corresponding p-value. If the p-value < 0.05 , then we can reject the null hypothesis of the ANOVA and conclude that there is a statistically significant difference between group means. For our case, the feature is selected if the p-value after the F-test between the target feature and handcrafted features is less than 0.05. after conducting this test, we obtained the following top 10 features:(’cred’, ’normalize_influence’, ’URLs’, ’PERSON_percentage’, ’Word count’, ’present_verbs’, ’past_verbs’, ’pronouns’, ’capitals’, ’short_word_freq’)
The results in Table 2 represent the weighted average of each evaluation measure.Our evaluation explored the effectiveness of hand-crafted features for fake news classification. Two set of features were investigated: one utilizing all available hand-crafted features and another incorporating only the top 10 most informative features identified through a feature selection process. While the model using all features achieved a certain level of accuracy, the model leveraging the top 10 features achieved comparable performance but less accurate than using all features. This suggests that dimensionality reduction through feature selection can be an alternative beneficial for fake news classification. While retaining all features might capture a broader range of potential indicators, it can also introduce noise and redundancy that can hinder model performance. Focusing on the most informative features allows the model to learn more effectively from the data, potentially leading to similar or even better classification accuracy with a more streamlined feature set. Further research could investigate the specific characteristics of the top 10 features to gain deeper insights into the most effective indicators of fake news content.
However, if we look more carefully at the results, we can observe that Logistic Regression, Support Vector Machine (SVC), and Gaussian Naive Bayes show quite small improvement when using only the top 10 handcrafted features. The ROC plots in Figs. 4 and 5 indicate clearly that using all handcrafted features would be more accurate than using the top 10 handcrafted features. Although feature selection algorithms often tend to produce accurate results than using all features, the use of one-way ANOVA would be the reason for these fluctuating results. Therefore, as part of future work is to apply different wrapper and filter feature selection algorithms. Initial observations from these findings suggest that employing text embedding features yields more precise outcomes in comparison to handcrafted features. Further investigation into this matter is warranted. Notably, concerning the word2vec outcomes, it is evident that the KNN and SVC models exhibit superior performance, whereas Random Forest emerges as the preeminent model based on TF-IDF. Consequently, there exists a discernible lack of consensus derived from these results.

This is inherently plausible as these models leverage sophisticated learning architectures with attention mechanisms. Furthermore, it was observed that RoBERTa yields marginally superior results compared to the original BERT model. Typically, BERT relies on random token masking and prediction. However, the RoBERTa implementation conducts masking during training, resulting in each sentence undergoing masking upon incorporation into a minibatch. Consequently, the potential for diverse masked versions of each sentence is not constrained as in BERT.

Discussion Based on the above results we reached to answer the proposed research questions.
- Answer of research question 1: which features are enough to build an accurate fake news detection system based on Truth seeker dataset?
From the results of three experiments, we surprisingly found that applying machine learning algorithms on text representation embedding features produce more accurate results than using only handcrafted features. Surprisingly,we found that the performance of classification model degraded when we combined handcrafted features with text representation embedding features. Therefore we can confirm that using text embedding features are enough to produce good results. Finally, we rise another concern about instability of machine learning algorithms with different categories of features. In other words, we cannot reach to stable conclusion that a single model can outperform the others. However, the Random Forest and AdaBoost are considered the most accurate models among the others.

- Answer of research question 2: Which kind of text representation is more suitable for this dataset?
The results of using text embedding features are summarized in Tables 5 and 6 and Figs. 6,7,8 and 9. From the results we found word2vec performs better than TF-IDF and it has ability to learning embedding vectors more efficiently. TF-IDF relies mainly on counting which makes it unable to understand the best representation for the text. In spite of that, the BERT and RoBERTa language models provide better text representation that help machine learning to classify news into fake or real. Therefore using such language model with machine learning are sufficient to produce better results even when they combined with handcrafted features.



Conclusions The rapid growth of social media platforms like Twitter has created an environment where unverified and untrustworthy platforms can easily disseminate fake news, posing a significant challenge to researchers. Finding a reliable annotated dataset that can help in building a fake news detection system is a critical issue. In this paper, we investigate the performance of one of the recent collected and labeled dataset called Truth seeker dataset. This dataset has been annotated using rigours system based on Amazon Mechanic Turk in addition to a group of experts. This dataset contains two categories of features: handcrafted features that describe various linguistic information about the tweet in addition to text features. To examine the performance of these features, we conducted multiple experiments using different text representation techniques and machine learning algorithms. Our experiments, based on the Truth Seeker Dataset, involved a combination of handcrafted features and text representations, including TF-IDF, BERT, and RoBERTa. Notably, the Random Forest and AdaBoost algorithms yielded remarkable results, achieving classification accuracy, recall, and F1-score when combined with TF-IDF text representation and handcrafted features.
However, throughout the experiment results, we found that using text embedding features with a machine learning classifier would be more accurate than using handcrafted features only. Amongst them, BERT and RoBERTa are the most superior techniques. Another important finding was that using Handcrafted features with text embedding features degraded the performance of classifiers more than using embedding features alone.
In future work, we will explore hybrid approaches that leverage multiple models and techniques to enhance the efficiency of fake news detection. We will search for different reliable datasets and apply different feature selection algorithms, such as wrapper and filter methods.
